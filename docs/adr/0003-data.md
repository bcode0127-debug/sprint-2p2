# ADR 0003: Data and splits

Date: 2026-10-23. Status: accepted.

## Context

The main run has 40 games of 5 agents over 10 rounds (2,000 agent-rounds); the pilot has 3 games (150). Held-out data must stay untouched until the analysis is frozen.

## Decision

Commit the raw logs under `data/raw/` with `SHA256SUMS` (scanned for key patterns first). Splits: dev = pilot plus main trials 0 to 9; threshold = main trials 10 to 19; test = main trials 20 to 39. Scored rounds are 1 to 9; round 0 is kept as a separate set because it has no history. Splits are cut in `src/sprint2p2/splits.py` and tested for size and disjointness (585 dev, 450 threshold, 900 test cases).

## Alternatives considered

Random case-level splits (rejected: cases from one game are correlated, so a case split leaks). Fewer held-out games (rejected: too few clusters for a game-clustered bootstrap).

## Consequences

All inference resamples whole games. Dev numbers are for design decisions only and are labelled DEV-ONLY wherever they appear. The raw logs make every score reproducible from the repo.
